Подключение игры в «Новое приложение»

Игра Block Blast полностью готова к работе внутри iframe (для huEVO, VK Mini Apps или любого вашего сайта).

Шаг 1. Скачайте файл игры

Сохраните этот HTML-файл и переименуйте его в index.html. Внутри него уже встроены стили, графика, звуки и сохранения.

Шаг 2. Залейте на бесплатный HTTPS-хостинг (за 1 минуту)

Так как платформа открывает игру во фрейме (https://...), загрузите index.html на любой бесплатный хостинг статических сайтов:

  • GitHub Pages или Vercel — бесплатный домен вида https://block-blast.vercel.app
  • Netlify Drop (app.netlify.com/drop) — просто перетащите папку с файлом index.html мышкой в браузер
Шаг 3. Вставьте ссылку в поле «Адрес игры»

В окне создания приложения укажите:
• Тип: Игра
• Название: Block Blast
• Адрес игры: ваша полученная HTTPS-ссылка, затем нажмите «Создать»!

📖 Правила Block Blast

🧩 Заполняйте сетку 8×8
Перетаскивайте 3 цветные фигуры снизу на свободные клетки поля. Как только вы выставите все 3 фигуры, появится новая тройка.
🔥 Взрывайте линии и копите КОМБО
Когда любая горизонтальная строка или вертикальный столбец из 8 клеток заполняется целиком — блоки взрываются! Очищайте линии подряд, чтобы увеличивать множитель серии.
🔨 Бустеры в трудный момент
Используйте Молоток, чтобы разбить любой мешающий блок на поле, или Обновление, чтобы заменить текущие 3 фигуры на новые.
